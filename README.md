# AI 代码修复实验室（Agent Code Repair Lab）

面向腾讯智囊团 ExpertHub「代码 / 编程」方向的个人技术作品之一。通过 10 个真实 Bug 修复案例，展示「识别错误 → 分析根因 → 修复 → 逐用例复测 → 人工审查」的完整代码修复与评测流程。

## 真实性原则

- 不伪造任何模型调用记录或测试结果。
- 所有 `pre_fix_results` / `post_fix_results` 均由本仓库自带的隔离执行器（`executor/`）在独立子进程中**真实运行**原始代码与修复代码后生成。
- 执行器与 CodeEval Lab 同源，采用进程级隔离（Windows 下 Job Object），已内置于本仓库，可独立运行。
- AI 辅助分析与复测的部分如实标注，人工审查要点与最终评价随案例归档。

## 10 类 Bug 修复案例

`cases/` 下每个案例有 JSON（结构化数据）与 Markdown（可读报告）两份，覆盖：逻辑错误、边界条件、空值处理、数据结构、异常处理、算法效率、类型处理、SQL 构造、资源泄漏、安全（SQL 注入）10 类问题。

每个案例包含：题目 → 原始代码 → Bug 成因 → 修复要求 → AI 辅助修复过程 → 修复后代码 → 测试用例 → 修复前真实结果 → 修复后真实结果 → 人工代码审查 → 最终评价。

**真实结果**：25 个用例，修复前 **10/25** 通过，修复后 **25/25** 通过；逐用例记录实际返回值、错误信息与真实耗时。`cases/summary.md` 为汇总。

## 复现

```bash
python scripts/run_cases.py
```

脚本会重新调用执行器真实运行每个案例的原始代码与修复代码，更新 `cases/*.json`、`cases/*.md`，并把带时间戳的过程记录写入 `execution_log.md`。需要 Python 3.10+（已在 3.13 验证）。

## 仓库结构

- `cases/`：10 个案例的 JSON / Markdown 与汇总 `summary.md`
- `executor/`：内置独立子进程执行器（`executor.py` + `runner.py`）
- `scripts/run_cases.py`：批量真实执行与报告生成脚本

## 安全边界

用户代码在独立子进程执行，非容器级沙箱；只应在本地 / 可信网络运行，禁止暴露到公网。
