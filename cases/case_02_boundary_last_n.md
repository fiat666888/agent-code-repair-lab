# 案例 C02：取末尾 N 个元素时 n=0 的边界错误

## 1. 编号

- 编号：C02　类别：边界条件错误

## 2. 问题描述

函数 last_n(items, n) 应返回列表 items 的最后 n 个元素。当 n=0 时应返回空列表；当 n 大于列表长度时应返回整个列表。原始代码直接使用负索引切片 items[-n:]，n=0 时 -0 等于 0，切片退化为整个列表。

## 3. 原始代码

```python
def last_n(items, n):
    return items[-n:]
```

## 4. Bug 原因

Python 中 -0 == 0，因此 items[-0:] 等价于 items[0:]，返回全部元素而非空列表。缺少对 n <= 0 的边界显式处理。

## 5. 修复要求

在切片前显式判断 n，当 n 为 None 或 n <= 0 时直接返回 []；n 大于长度时由 Python 切片天然返回整个列表，保持不变。

**分析步骤**

**修复步骤**

1. 保留原有切片语句处理正数 n。

## 7. 修复后代码

```python
def last_n(items, n):
    if n is None or n <= 0:
        return []
    return items[-n:]
```
