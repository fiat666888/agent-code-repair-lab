# 案例 C04：用列表当作字典统计词频

## 1. 编号

- 编号：C04　类别：数据结构使用错误

## 2. 问题描述

函数 count_frequencies(items) 应统计列表中每个元素出现次数并返回字典。原始代码错误地用列表（list）作为计数器容器，调用列表并不存在的 get 方法，且试图用字符串作为列表下标。

## 3. 原始代码

```python
def count_frequencies(items):
    counts = []
    for item in items:
        counts[item] = counts.get(item, 0) + 1
    return counts
```

## 4. Bug 原因

选择了错误的数据结构：列表不支持以字符串键读写，也没有 dict.get 方法。应使用字典（dict）以元素为键计数。

## 5. 修复要求

将 counts 初始化为空字典 {}，其余计数逻辑保持不变。

## 6. AI 修复过程

- 执行者：本次由 AI 辅助完成定位与修复（CodeBuddy Code 执行分析与改写）

**分析步骤**

1. 阅读代码发现容器初始化为列表 []，随后却按 key 方式访问并调用 .get()。
1. 确认列表既无 get 方法也不能以字符串为下标，判定为数据结构选择错误。
1. 明确统计词频的正确结构是字典，键为元素、值为计数。

**修复步骤**

1. 把 counts = [] 改为 counts = {}。
1. 保持循环体 get+1 的计数逻辑不变。

## 7. 修复后代码

```python
def count_frequencies(items):
    counts = {}
    for item in items:
        counts[item] = counts.get(item, 0) + 1
    return counts
```
